Distributed Systems Course Package

Files:
- index.html: ebook/lab PDF viewer
- studio.html: practice and timed exam application
- question_bank.json: 250-question external bank
- Distributed_ebook_2025a.pdf
- LabManual-DistributedSystems.pdf

Recommended launch:
1. Extract the ZIP.
2. In the extracted folder run: python -m http.server 8000
3. Open: http://localhost:8000

A web server is required because browsers normally block fetch() from file:// pages.
